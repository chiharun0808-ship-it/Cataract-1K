# frame11位置バイアス検証結果

検証プローブ数: 30（test splitから等間隔サンプリングした異なる実フレームを使用）


## 内容を完全に同一化(30枚とも同じ画像)した場合のargmax位置の分布
argmax_frame_when_content_identical
11    19
30    11

- argmaxが11番目だった割合: 63.3%
- argmaxが30番目(自己)だった割合: 36.7%

## 判定
内容を完全に同一化しても、多くのプローブでargmaxが11番目に留まった。
これは「11番目への集中」が映像内容ではなく、TimeSformerのtime_embed由来の
固定的な位置バイアスであることを強く示唆する（内容の差がゼロでも再現するため）。

## 注意点
- 種フレームには実際にテストウィンドウの最終フレーム(query位置の本物の画像)を使用。
  ゼロ埋めなど不自然な画像は使っていない。
- 30枚とも同一画像なので、patch_embedから来る内容由来の寄与はフレーム間で完全に
  等しくなる。したがって位置ごとの差が残るなら、その差の発生源は
  (a) time_embed（位置埋め込み、内容非依存）、または
  (b) Attention計算そのものに内在する非対称性（数値的な理由等）
  のいずれかであり、『特定フレームの映像内容』ではあり得ない。
- 参考として実データ(analyze_temporal_attention.pyの881件平均)のカーブと重ねて
  identical_content_vs_real_content.png に可視化した。
