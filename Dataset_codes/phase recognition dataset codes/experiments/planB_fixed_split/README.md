# 案B: planB_fixed_split（既存の test を保った比較実験）

## 目的
既存の test 11症例・val 11症例をそのまま保ち、同じ条件で学習し直したモデルどうしを比べる。
既存のモデル（旧モデル・現行モデル）は、同じ test で測った**参考値**として並べるだけにし、
差の原因は主張しない（2026-10-02 合意）。

期間: 進捗報告までの約20日間（2026-10-02 から）。その後、案A（分け直したデータでの確認）を行う予定。
