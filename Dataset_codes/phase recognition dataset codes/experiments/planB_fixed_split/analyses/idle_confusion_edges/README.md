# 候補C: 増えた idle の取り違えは、画面の端が切れたせいか（2026-10-05）

再調査のモデル（defectfree_f30_i333ms_s5s_vitprep、一致率 82.79%）で増えた idle の取り違えが、
中央の切り出しで画面の端が失われたことと関係するかを、読むだけの分析で確かめた。スクリプト: `measure_idle_confusion_edges.py`

- 対象: test 11症例で、現行モデルは正解・再調査のモデルは不正解、かつ idle が絡む 418 時点
  （正解 idle → 別フェーズ 245、別フェーズ → idle 173）。全11症例に 23〜59 時点ずつある
- 対照: 両モデルとも正解だった時点から、同じ症例で同じ数（418）をランダムに選んだ
- 見たもの: 窓の末尾フレームの「明るい画素のうち、切り出しで切れる部分に入る割合」と、画像の目視

## 結果
| | 中央値 | 上位10%の境目 | 5%以上が切れる割合 |
| --- | --- | --- | --- |
| 新たな取り違え（別フェーズ → idle） | 0.46% | 10.3% | — |
| 新たな取り違え（idle → 別フェーズ） | 0.43% | 3.4% | — |
| 新たな取り違え（全体） | 0.44% | — | 8.6% |
| 対照（両方正解） | 0.31% | 2.7% | 8.1% |

- 取り違えの方が端の明るい画素がわずかに多い（中央値 0.44% と 0.31%、Mann-Whitney の片側 p=0.027）。
  ただし差は 0.1 ポイント程度と小さく、1秒ごとの時点は互いに似ているので p 値は参考値。
- 目視（`plots/`）: 「正解は手術中のフェーズなのに idle と予測」した場面の多くで、器具（カニューレ、ナイフなど）は
  **切り出す範囲の中に見えていた**。器具の柄の一部が下側の枠にかかる場面はあるが、先端は枠の中にあった。
  「正解は idle なのに別フェーズと予測」した場面は、器具が映っていない眼の画面や、暗い・ぼけた画面だった。

## 言えること・言えないこと
- 言える: 窓の末尾のフレームを見る限り、取り違えの多くは「器具が切り出しで消えた」ことでは説明できない。
  中央の切り出しが主な原因だという仮説（原因の候補1）は、強くは支持されない。
- 言えない: 窓の30枚のうちほかのフレームの端に器具があったか。切り出しの影響がまったくないとまでは言えない。
- 残る候補: 学習の進め方の違い（再開・optimizer の作り直し・early stopping）、乱数のばらつき、正規化など前処理全体の変化、
  学習画像の違い（mp4v → PNG）。どれかを分けるには学習が必要。
