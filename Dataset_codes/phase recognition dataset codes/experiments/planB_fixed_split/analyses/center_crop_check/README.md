# 中央切り出しで失われる情報の確認（2026-10-05）

事前学習の前処理（短い辺を256 → 中央224×224）に合わせた場合に、512×384 の画像の端から何が失われるかを、
読むだけの分析で確かめた。学習・推論はしていない。スクリプト: `measure_center_crop_loss.py`

- 残る範囲（元画像の座標）: x 88〜424、y 24〜360。左右それぞれ約17%、上下それぞれ約6%が切れる
- 対象: train と val の全窓の末尾フレーム 3,510枚（frames/repro-baseline/）

## 結果
| 指標 | 中央値 | 上位10%の境目 | 10%以上失うフレームの割合 |
| --- | --- | --- | --- |
| 明るい画素（グレー値100以上）のうち切れる部分に入る割合 | 0.6% | 2.5% | 2.6% |
| 輪郭の画素（Canny）のうち切れる部分に入る割合 | 12.3% | 24.2% | 63.8% |

- フェーズごとに見ても、明るい画素の中央値は 0.4〜0.8% で、どのフェーズでも大きな差はない。
- 失う割合が大きいフレーム（`plots/top_loss_frames.png`）は、ほとんどが idle の暗い・ぼけた画面か、
  カメラの前を横切る手や指のぼけた影。器具の先端や瞳孔が切れている例は、上位12枚には見られなかった。
  case_5261（LensPositioning）では、右端のリング状の物の一部が切れていた。
- 輪郭の画素の割合が大きいのは、暗い背景や布の細かい模様・ノイズも輪郭として数えるためと考えられる
  （上位のフレームを見る限り、器具の輪郭ではない）。

## 言えること・言えないこと
- 言える: 明るい物（眼球・器具・反射）のほとんどは、切り出す範囲の中に収まっている。
- 言えない: 切れる部分の情報が、フェーズの判断に役立っているかどうか（学習して比べないと分からない）。
- 明るさと輪郭による目安で、器具を直接検出したわけではない。
