# 誤りの隣接・非隣接の内訳（2026-10-05）

現行モデル（91.36%、誤り 379 時点）と再調査のモデル（82.79%、誤り 755 時点）の誤りを、隣接・非隣接に分けた。
読むだけの分析。スクリプト: `classify_error_adjacency.py`

## 定義
- 定義1（既存の attention 分析と同じ）: idle が絡む誤りは「idle絡み」として別枠。手術フェーズどうしは、標準の手術順序で差が1なら「隣接」、2以上なら「非隣接」
- 定義2（その動画の実際の流れ）: 予測が、誤りの時点を含む区間の直前・直後の区間のラベル、または idle を飛ばした直前・直後の手術フェーズと同じなら「時間的に隣接」、そうでなければ「時間的に非隣接」
  - 最初は idle を飛ばさずに数えていたが、ほとんどのフェーズの間に idle がはさまるため、手術フェーズどうしの誤りがすべて非隣接になってしまった。idle を飛ばした前後も隣接に含めるよう直した

## 結果（定義2）
| 誤りの種類 | 現行: 隣接 | 現行: 非隣接 | 再調査: 隣接 | 再調査: 非隣接 |
| --- | --- | --- | --- | --- |
| 手術フェーズどうし | 116 | 105 | 155 | 93 |
| 正解 idle → 予測が別フェーズ | 44 | 21 | 244 | 38 |
| 正解が別フェーズ → 予測 idle | 93 | 0 | 225 | 0 |
| 合計 | 253 | 126 | 624 | 131 |

- 誤りの増加（+376）のほとんど（+371）は「時間的に隣接」で、そのうち +332 は idle が絡む誤り。
- 時間的に非隣接の誤りは 126 → 131 で、ほぼ変わらない。中身は入れ替わった
  （LensPositioning → AC Flushing が 50 → 29 に減り、AC Flushing → Tonifying が 30 に増えた）。
- 再調査のモデルの idle が絡む誤りは、すべて区間の境目から10秒以内（現行も 96〜99%）。
- 定義1 では、idle絡み 158 → 507、隣接 99 → 127、非隣接 122 → 121。

## 言えること
- 再調査のモデルで増えた誤りは、ほぼすべて「フェーズの切り替わりの前後で、前後のフェーズや idle と取り違える」種類。
  手術の流れと無関係なフェーズへの取り違え（非隣接）は増えていない。
- 予測の切り替わり回数が減った（517 → 327）こととあわせると、切り替わりへの反応が遅くなった可能性がある（未確認）。
