# papers/ — 読んだ論文の置き場

## ルール

- **フォルダは分けない。** 分類はすべて `index.md` の表のタグで行う。
- **ファイル名 = 引用キー**：`発表年4桁_筆頭著者の姓(小文字)_題名の最初の意味のある英単語(小文字)`
  - 例：`2026_liu_stabilizing.pdf` / `2026_liu_stabilizing.md`（メモ）／ 本文では `\cite{2026_liu_stabilizing}`
  - 「A」「An」「The」「On」など意味の薄い語は飛ばす（A Framework for … → `framework`）。
  - Google Scholar 等の BibTeX はキーが `liu2026stabilizing` 形式なので、貼るときにこの形式へ書き換える。
  - 同じキーがすでにあれば末尾に `b`, `c` を付ける（`2026_liu_stabilizingb`）。
  - 著者が分からないうちは `年_tbd_代表語` にしておき、分かったら付け直す。
  - 数字で始まるキーに対応しないツールに当たったら、先頭に `y` を付ける（`y2026_liu_stabilizing`）。
- **PDF はgitに入れない**（`.gitignore` で `papers/**/*.pdf` を除外）。gitで管理するのは `index.md`・`refs.bib`・メモ（`.md`）だけ。
- **メモ**：PDF と同じ名前の `.md`。ひな形は `_template.md`。
- **発表月**は `index.md` の「発表」列に `YYYY-MM` で書く。どの日付を使うかは次のとおり。
  - 会議論文：会議の開催月／雑誌論文：オンラインで公開された月／arXiv だけの論文：v1 が出た月。
  - arXiv の後に会議・雑誌に載ったら、正式に出版された方の月を使い、arXiv の月はメモに書く。
  - 分からないものは `YYYY-??`。
- 論文になっていない資料（GitHub だけ等）は `tbd_代表語` のキーで一覧表に入れ、refs.bib には入れない。
- **refs.bib**：論文を書くときに `\cite{キー}` でそのまま使う。分からない項目は空欄にせず書かない（でっちあげない）。

## タグの一覧（index.md で使う）

| 列 | 値 |
|---|---|
| 著者の立場 | 医者 / 工学系 / 混合 / 未確認 |
| テーマ | 揺れ, 遅れ, 汎化（他施設で使えるか）, 臨床（医者の視点）, ラベル・データセット, 評価方法, 手法一般 |
| なぜ読む・何に使う | 自分の研究のどこに使うかを一文で（例：「揺れはラベルが大まかなせい？」を確かめる根拠） |
| 状態 | 読む候補の表：未取得（PDF なし）/ 未読 / 流し読み。読んだ論文の表：読んだ（和訳あり など） |

タグは増やしてよい。増やしたらこの表にも書き足す。

## 著者の立場（医者 / 工学系）の決め方

著者の所属と発表した場所を見て決める。決めた理由はメモの「著者：」欄に書く。

| | 医者 | 工学系 |
|---|---|---|
| 所属 | Department of Ophthalmology、病院、医学部 | Engineering、Computer Science、ロボット系の研究室 |
| 発表した場所 | Ophthalmology、JCRS、Surgical Endoscopy などの医学誌 | MICCAI、IPCAI、WACV、IEEE 系、arXiv |

- **混合**：医者と工学系の研究者が一緒に書いている論文（手術動画の研究に多い）。筆頭著者がどちらかもメモに書いておく（論文の視点がどちら寄りか分かる）。
- **未確認**：PDF がなく所属を確かめていないもの。推測で決めたときはメモに「推測」と書き、PDF を手に入れたら確かめて直す。
- 要件（何が必要か）を考えるときは医者側の論文を重視する。
- 調べるとき：`index.md` で「医者」などを検索する。または Claude に「医者が書いた論文だけ出して」と頼む。

## 全文の和訳（頼まれた論文だけ）

- **ライセンスで翻訳が認められている論文（CC BY など）だけ全文和訳する。** 改変禁止（CC BY-ND、CC BY-NC-ND）や arXiv の標準ライセンスの論文は、全文和訳の代わりに**日本語の詳しい要約**（章ごとの要約＋主要な表の数値）を同じ名前 `キー_ja.html` / `キー_ja.pdf` で作る。冒頭にどちらかを書き、メモの「ライセンス」欄にも書く。
- 原文の隣に `キー_ja.html`（和訳の元ファイル）と `キー_ja.pdf`（和訳の PDF）を置く。どちらも著作権のため gitに入れない（.gitignore で除外）。
- 訳し方：和訳だけ。段落ごとに〔p.8〕のように原文のページを付ける。専門用語は英語を添える。参考文献の一覧は訳さない。冒頭に「機械翻訳なので引用は原文から」と書く。
- 図：原文の図を画像で切り出して貼る（`<img data-page="7" data-rect="x0,y0,x1,y1">`）。図中の英語は下に「図中の語」として訳を添える。
- 表：原文と同じ行と列で日本語に組み直す。数字は原文と照合する。横長の表は `<div class="landscape">` で横向きのページにする。
- PDF の作り方（リポジトリのルートで）：`python -I papers/_tools/make_ja_pdf.py papers/キー_ja.html`
  - 必要なもの：PyMuPDF（`pip install pymupdf`）と Microsoft Edge（Windows に標準で入っている）。
- 誤訳を見つけたら `キー_ja.html` を直して、上のコマンドで PDF を作り直す。

## 新しい論文を登録する手順

1. PDF をダウンロードし、Claude に「この論文を登録して」と頼む（または自分で以下を行う）。
2. 引用キー（`年_著者_単語`）を決めて、PDF を `papers/キー.pdf` に置く。
3. `index.md` の「読む候補」の表に 1 行足す（読んだら「読んだ論文」の表に移す）。
4. `refs.bib` に BibTeX を足す（出版社や arXiv のページの「Cite」からコピー）。
5. `_template.md` をコピーして `キー.md` を作り、読んだらメモを書く。
