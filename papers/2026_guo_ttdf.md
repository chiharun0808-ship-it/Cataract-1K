## 一言で
遅れを数字で出している唯一の論文。余計な切り替わりを減らすほど、遅れの中央値が増える。

## 何をしたか
- Cholec80、1 fps。凍結したオンライン認識器（DINOv2 + 因果的 MS-TCN）の出力から、切り替わりを 2 段階で絞り込む。
  - 段階 1：最低継続時間 d（5 フレーム）＋ train から作った「起こりうる順番」のグラフで確認。
  - 段階 2：小さな因果的 TCN で、本物の切り替わりか判定。

## 結果（Table 1, test）
- 余計な切り替わり / 正解：6.57 → 2.43 → 1.36 → 0.60
- 捉えた割合：0.67 → 0.64 → 0.64 → 0.53
- 遅れの中央値：0 → 5.0 → 5.0 → 6.3

## 自分の研究との関係
- 関係するテーマ：揺れと遅れ
- 論文が明示するトレードオフは「捉える割合 vs 余計な切り替わり」だけ。遅れは「抑えたまま」と書くだけで、d を変える実験はない → 揺れと遅れを正面から測るのは新しさになりうる。
